# Form, wordmarks and lockups

## Choosing the form
The categories — wordmark, letterform, emblem, pictorial, abstract — blur, and none is right by rule (Wheeler pp. 48–49). The branch is the name and where the mark lives:

- **A short, distinctive name → a wordmark** alone is often enough (Identify, Introduction; Dime).
- **A long or unwieldy name, or parts to unify → a symbol** that stands in for it; a long wordmark would have to shrink into small spaces (Identify, HarperCollins; Merck; Chase Manhattan).
- **A generic name → treat one part of it visually** to make it distinctive (Identify, Showtime; Centro).
- **Initials → only when people already use them**, and never one letter pulled out of an acronym people say whole (Identify, EPA; NBC).
- **A letterform mark** is a mnemonic and sits in an app tile easily (Wheeler p. 54).
- **An abstract mark** buys ambiguity for a broad or technical offer and is the hardest to do well; it gains meaning through exposure (Wheeler p. 58; Identify, Chase Manhattan).
- **A pictorial mark** when it must be read fast in a cluttered setting (Identify, Old Chatham).
- **A name inside a shape** is the hardest form to read small (Wheeler p. 60) — unless the name is set tight to the edges of a square tile, which holds on stickers and poster corners (Identify, Mount Sinai; UNDP; Downtown Alliance). A ring of type around a symbol keeps a bare version with the type moved below for small uses (Identify, Bicentennial). A plain disc behind the mark is different: it shields it on dark or busy ground (Identify, PBS; WTA; Smithsonian; Mobil).
- **Beside other marks it would fight** — sub-brands, partner logos — drop the symbol (Identify, Hearst).

## Wordmarks
- **Simple lettering plus one device** — the red O, the dot, the check (Identify, Mobil; Dime). Shown twice where once goes unnoticed (Identify, Gemini). The strongest devices **remove** rather than add: a missing crossbar or spine, the gap carrying the idea (Identify, Centro; WTA; Factset).
- **Hand-tune it.** Spacing, stem weight and stroke width are where a set word becomes a mark; the tweaks go unnoticed and make the effect (Identify, Barneys; Showtime).
- **Letters share the symbol's stroke and geometry** (Identify, Rockefeller Center; Time Warner). A face with a meaningful origin beats a neutral one when one exists (Identify, Library of Congress; PBS).
- **Stacking or a divider forces the right reading** of a name that misreads run together (Identify, MIAD; SEW Infrastructure).
- **The letter traits grow into an alphabet** for product and sub-brand names (Identify, Opet; Mobil; Harvard Maintenance).

## Lockups
- **The signature is a fixed relationship** of mark, name and any tagline, in horizontal and vertical versions (Wheeler p. 48).
- **Symbol height = the name block**, from the first line's cap top to the last line's baseline: a two-line name gets a two-line-tall symbol, and further lines hang below without the symbol growing (Identify, Library of Congress; Conservation International; National Geographic; Smithsonian; MBTA).
- **A secondary name is set apart by one contrast** — smaller and lighter, aligned to the name's edge rather than the symbol's (Identify, Merck; Hearst), or the same size in another colour or italic (Identify, Grey; Harvard Maintenance; Smithsonian; National Geographic).
- **Symbol and wordmark also stand apart.** A lockup too crowded for a space is split, not shrunk (Identify, Mobil; Beehouse).
- **Ship each colour positive and reversed in a box**, as a set (Identify, Showtime; El Mall).
- **The app icon** takes the letterform, the shorthand, the abstract mark, or a wordmark only if it stays legible at tile size (Wheeler p. 75; Identify, Do@).
